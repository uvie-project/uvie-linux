UVie for Linux - APT Repository

Debian/Ubuntu (x86_64) repository for the UVie Vietnamese input method.

Setup

curl -fsSL https://uvie-project.github.io/uvie-linux/uvie-repo-key.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/uvie.gpg
echo "deb [signed-by=/usr/share/keyrings/uvie.gpg] \
  https://uvie-project.github.io/uvie-linux stable main" \
  | sudo tee /etc/apt/sources.list.d/uvie.list
sudo apt update

Packages

Pick ONE input path - do not run uvie-inputd while a framework engine is active.

  • uvie - standalone daemon (uvie-inputd) + settings UI
  • ibus-uvie - IBus engine
  • fcitx5-uvie - Fcitx5 addon
sudo apt install uvie        # daemon + settings UI (standalone)
sudo apt install ibus-uvie   # IBus
sudo apt install fcitx5-uvie # Fcitx5

Source: github.com/uvie-project/uvie-linux
